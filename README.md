## 🤝 Contributing

Contributions are welcome and encouraged! To keep this resource organized and high-quality, please follow these guidelines:

### How to Contribute

1. **Fork** this repository
2. **Create a new branch** for your additions: `git checkout -b add-new-resources`
3. **Add your resources** to the appropriate category section following the existing format:
   ```markdown
   | # | [Tool Name](https://url.com/) | One-sentence description of what it does and why it's useful. |
   ```
4. **If no category fits**, create a new section with a descriptive emoji-prefixed header (e.g., `## 🔬 New Category Name`)
5. **Commit** with a descriptive message: `git commit -m "docs: add [resource-name] to [category]"`
6. **Submit a Pull Request** with a brief explanation of what you're adding

### Contribution Rules

- ✅ **Do** add resources that are genuinely useful and actively maintained
- ✅ **Do** write clear, concise one-line descriptions for every link
- ✅ **Do** place resources in the most relevant existing category
- ✅ **Do** check for duplicates before submitting
- ❌ **Don't** submit broken or dead links
- ❌ **Don't** add referral or affiliate links
- ❌ **Don't** submit low-quality or spam sites
